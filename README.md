💜 Multilingual Love Heart

A Python generative art project that creates a heart-shaped composition using the phrase "I love you" in 20 different languages.

✨ Features

- 💖 Heart-shaped typography formed by multilingual love phrases.
- 🌈 A colorful palette featuring crimson, pink, violet, and blue.
- 💫 Neon glow effects and glowing text.
- ⭐ Animated sparkles that appear and disappear.
- 💓 A soft pulsing heartbeat animation.
- 🌌 A starry background with subtle animated effects.

🛠️ Technologies

- Python 3
- Tkinter
- Turtle Graphics
- Math and Random modules

🚀 How to Run

Make sure Python 3 is installed on your computer.

Open a terminal in the project folder and run:

python love_original.py

On Windows, you can also use:

py love_original.py

🎨 Customization

The colors, typography, glow intensity, sparkles, and animation settings can be modified in the Python source code.

📌 About

A creative coding experiment combining typography, mathematical shapes, colors, and animation to create a romantic visual effect.
