✦ About the project

Love Heart is a small Python project that combines programming and creativity to create an animated heart with multilingual romantic messages.

The project was created to explore Python's graphical capabilities while experimenting with animation, visual design and text presentation.

Every detail was designed to give the experience a personal touch.

♡ Features

- Animated heart created with Python.
- 20 romantic phrases in different languages.
- Custom dark visual theme.
- Graphical interface using Python libraries.
- No external dependencies required.

⚙️ Technologies

Technology| Purpose
Python| Main programming language
Turtle| Heart animation and graphics
Tkinter| Graphical interface

🚀 Getting started

Requirements

- Python 3 installed.
- Tkinter available with your Python installation.

Run locally

1. Clone the repository:

git clone https://github.com/Gianissssss/love_heart.git

2. Open the project folder:

cd love_heart

3. Run the application:

python love_original.py
